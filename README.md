# Career Quest

Career Quest показывает сотруднику карьерную цель, разрыв навыков и следующий шаг развития с объяснением. HR видит агрегированную картину развития команды.

## MVP

- Профиль сотрудника с целью, текущими и требуемыми уровнями навыков.
- До трёх рекомендаций с evidence и раскрываемой оценкой, если она доступна.
- Демо completion обновляет уровень навыка и список шагов.
- Отдельная HR-панель с агрегатами и состояниями участия.
- Переключение демо-роли и интерфейса RU/KK.
- Адаптивный интерфейс без сборщика и сторонних frontend-зависимостей.

## Запуск

Из корня репозитория выполните:

```sh
go run ./web/server.go
```

Откройте <http://localhost:4173>. Для mock API используется режим по умолчанию. Состояние completion хранится в `localStorage`; кнопка «Сбросить демо» восстанавливает начальные данные.

Чтобы включить заготовленный HTTP adapter, откройте `http://localhost:4173/?mock=false`. Перед подключением backend согласуйте endpoint и DTO: текущие адреса в `web/src/api.js` — placeholders, поскольку backend-контракт в репозитории ещё не представлен.

## Demo-сценарий

1. Откройте приложение в режиме Employee.
2. Покажите роль, уровень и цель развития Алии.
3. Обсудите текущий и целевой уровни навыков, gap и critical-метку.
4. Раскройте «Почему эта рекомендация?» и покажите evidence.
5. Нажмите Complete: ответ mock API обновит прогресс и уберёт выполненный шаг.
6. При необходимости нажмите «Сбросить демо» для повторного показа.
7. Переключитесь в HR-панель и покажите только агрегаты команды.
8. Переключите язык на KZ и проверьте локализованный интерфейс.

## Роли и режимы

- **Employee** — собственный демонстрационный профиль; HR endpoint не запрашивается.
- **HR** — отдельная панель агрегатов.
- **Mock** — локальный адаптер в `web/src/mock.js`, активен по умолчанию.
- **HTTP** — заготовка adapter в `web/src/api.js`; включается параметром `?mock=false` после согласования реального контракта.

Demo role switch не является аутентификацией и не заменяет серверную проверку доступа. Числа и профиль в mock предназначены только для демонстрации.

## Ограничения

- Серверные DTO и endpoint пока отсутствуют; HTTP пути приведены как места подключения, не как подтверждённый контракт.
- Mock HR-аналитика статична, mock employee progress сохраняется локально.
- Подключение настоящего backend и автоматизированные браузерные E2E требуют опубликованного API и выбранного тестового раннера.
