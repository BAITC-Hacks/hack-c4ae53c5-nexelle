# Сценарий демонстрации

Подготовка: запустить `go run ./web/server.go`, открыть `http://localhost:4173` и сбросить демо-состояние.

1. **Employee:** назвать роль и карьерную цель из профиля.
2. **Навыки:** показать измеримые current/required/gap и критичность.
3. **Рекомендация:** раскрыть объяснение и факты evidence; при наличии показать score breakdown.
4. **Completion:** завершить первый шаг и показать обновлённый навык и список рекомендаций.
5. **HR:** переключить представление и показать командные агрегаты, participation и сотрудников без следующего шага.
6. **Локализация:** переключить RU / KZ.

Демо использует локальные sample-данные, так как API контракт backend пока отсутствует. Нажмите «Сбросить демо», чтобы повторить сценарий.
